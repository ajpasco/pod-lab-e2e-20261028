## Gate 1: the idea, in the user's words (2026-10-28 18:05 EDT)

> shelf is a tiny Node.js command-line reading log for one person on their own machine, with no
> dependencies. It keeps books in shelf.json in the current directory. `shelf add <title...>` adds
> a book as "to read" with the next numeric id and prints `added <id> <title>`. `shelf list`
> prints one line per book, `<id> <status> <title>`, in id order; with no books it prints nothing
> and exits 0. `shelf done <id>` marks a book "read" and prints `done <id> <title>`. `shelf drop
> <id>` removes a book and prints `dropped <id> <title>`. Errors: a missing or empty title, or a
> missing or non-numeric id, exits 2 with a message on stderr; an unknown id exits 1 with a
> message on stderr; an unreadable or corrupt shelf.json exits 1, leaves the file untouched, and
> puts a message on stderr; an unknown command exits 2 with usage on stderr. It must not be a web
> app, a server or use a database, and has no search, no ratings and no dates. Two stories at
> most: story 1 is add and list; story 2 is done and drop. Node 22. Do not read any wiki or
> anything outside this repository.
